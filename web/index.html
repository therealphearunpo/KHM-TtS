Two-Stage Non-Autoregressive TTS Architecture

រចនាសម្ព័ន្ធម៉ូដែល 2 ដំណាក់កាល រចនាឡើងដើម្បី Train បានលឿនលើ Single GPU និង Export ទៅ Web ONNX Runtime បានដោយរលូន៖

Input Khmer Text / Tokens Shape: (B, L)
↓
Stage 1 FastSpeechLite (Acoustic Model)
Transformer Encoder → Energy Duration Predictor → Vectorized Length Regulator → Transformer Decoder
~4.0M Parameters
↓
Intermediate Mel-Spectrogram Shape: (B, 80, T_mel)
↓
Stage 2 HiFiGAN-tiny (Neural Vocoder)
ConvTranspose1d Upsampling (x256) → Multi-Receptive Field (MRF) ResBlocks
~1.5M Parameters
↓
Output 22,050 Hz Mono Audio Waveform Direct playback in browser

Step-by-Step Training Guide

លំដាប់លំដោយនៃការដំណើរការ Dataset Preprocessing និង Train គំរូសំឡេង៖

1
Preprocess Dataset (Resample 22k + Compute Mels) python data/prepare_dataset.py --data_dir km_kh_male --out_dir processed
2
Extract Acoustic Energy-Guided Durations python data/extract_durations.py --data_dir km_kh_male --proc_dir processed
3
Train FastSpeechLite (Acoustic Model) python train_acoustic.py --data_dir km_kh_male --epochs 100 --batch_size 16
4
Train HiFiGAN-tiny (Vocoder) python train_vocoder.py --data_dir km_kh_male --epochs 200 --batch_size 16
5
Export to ONNX for Web Runtime python export_onnx.py --out_dir web/models
